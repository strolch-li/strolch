# Security Policy

## Supported Versions

Please use the table below to see if the version you are using is currently supported with security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 2.6.x   | ✅ |
| 2.5.x   | ✅ |
| < 2.5   | ❌ |

## Reporting a Vulnerability

If you find a security vulnerability, please report it by emailing eitch@eitchnet.ch. You can encrypt your message using KeyOxide with my public GPG key: https://kxd.eitchnet.ch/b1359c320a72a2907f1a7f7875db9c85c74331f7

We will then consider the vulnerability and shall try our best to close the vulnerability as soon as possible if it is part of an active branch and a fix is possible.
